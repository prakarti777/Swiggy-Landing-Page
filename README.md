# Swiggy Landing Page

A frontend landing page inspired by Swiggy, an online food delivery platform. The website showcases restaurants, food categories, and delivery options through a modern and visually appealing interface.

## 🚀 Features

- Swiggy-inspired homepage design.
- Navigation bar with logo and menu options.
- Food categories and restaurant sections.
- Restaurant and food cards.
- Promotional banners and offers.
- Food images and attractive layouts.
- CSS hover effects and transitions.
- Clean and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
